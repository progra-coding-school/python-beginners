What is cortex?

Cortex is a programming language.

Cortex is a high-leveled programming language.

CIC

CIC->cortex install client

Cic is the package manager of cortex.

Through cic you can install and uninstall packages.

CGFX

CGFX -> cortex graphics

cgfx is one of the module in cortex.

Through cgfx you can make Cortex draw extremely complex shapes,patterns.

By repeating simple instructions.
